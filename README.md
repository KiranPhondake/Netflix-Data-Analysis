This project explores and analyzes a dataset of movies available on Netflix, aiming to uncover insights into content trends, genres, release patterns, and more. The analysis is done using Python and includes data cleaning, exploratory data analysis (EDA), visualizations, and summary insights.



🛠️ Tools & Technologies:

Python

Pandas – data manipulation

NumPy – numerical operations

Matplotlib & Seaborn – data visualization

Jupyter Notebook – for code and analysis presentation
